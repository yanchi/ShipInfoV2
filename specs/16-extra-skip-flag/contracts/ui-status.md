# UI Contract: 臨時便の1行の「・抜港あり」

[specs/15-extra-voyage-badge/contracts/ui-status.md](../../15-extra-voyage-badge/contracts/ui-status.md) の「臨時便の1行」の「・抜港あり」の決め方を次のとおり変える。文言・位置・時刻・リンク・クラスは 15 のまま。

**上書きする決まり**：「今日を出る臨時便の運航のどれかで、その運航の最初と最後の港のあいだに寄らない港があれば」（ボードの行から逆算する）。

## 決め方

今日その方向の臨時便の行（状態が Extra・出港時刻あり。臨時便の1行の時刻を決める行と同じ）のうち、1つでも「この港を出たあとに抜港あり」（data-model.md の `skips_ports_after`）なら「・抜港あり」を出す。ボードのほかの日・ほかの行は見ない。

```
鹿児島〜那覇（下り）                    ▲ スケジュール変更
◆ 臨時便 名瀬 03:50発・抜港あり
```

## 例

| 日・方向 | 今日の臨時便の行 | 表示 |
|---|---|---|
| 10/27 マルエー下り | 名瀬 03:50（1）・本部 12:00（0） | ◆ 臨時便 名瀬 03:50発・抜港あり |
| 9/7 マリックス上り | 那覇 07:00（1）・名瀬 21:20（0） | ◆ 臨時便 那覇 07:00発・抜港あり |
| 9/27 マリックス上り | 名瀬 05:50（0） | ◆ 臨時便 名瀬 05:50発 |
| 終点の1個前（名瀬）を抜く上り | 那覇〜亀徳（1） | ◆ 臨時便 那覇 HH:MM発・抜港あり（**15 では出なかった**） |

変えないもの：バッジ（15）、会社詳細・港別ページの便の行、異常の要約、凡例、通知メール。
