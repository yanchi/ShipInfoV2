# Feature Specification: 検索語に合わせた会社ページの説明文と船の名前

**Feature Branch**: `19-search-query-wording`
**Created**: 2026-11-24
**Status**: Draft
**Input**: User description: "検索クエリに合わせた title・description・本文の改善（Search Console のクエリ分析より）。(1) 検索の9割以上が「運行状況」（誤字だが一般的）なのに、サイトは「運航状況」だけを使っている。title か description に「運行状況」も入れて、検索結果で一致して見えるようにする。(2) マリックスラインの会社ページ（/company/2）は「マリックスライン 運行 状況」で順位 4〜5 位なのに CTR が 0〜0.9%（表示回数 計約1,900）。公式サイトにない価値（リアルタイム・毎時更新・今日・明日以降もまとめて見られる・欠航や遅延がひと目でわかる）を title・description で前に出して CTR を上げる。「リアルタイム」付きクエリは CTR 6.75%、「明日」付きは 14% と高い。マルエーフェリーの会社ページ（/company/1）も同様。(3) 船名（フェリー波之上・フェリーあけぼの・フェリーあまみ・クイーンコーラルクロス・クイーンコーラルプラス など）や会社の別名（Aライン・エーライン・大島運輸 など）で計約400回表示されているが、受け皿がない。会社ページの description と本文に船名・別名を出す。スコープ外: 港ページへの内部リンク（島名でのリンク）は別機能にする。"

## 概要

18-port-seo-pages を公開したあとの検索の状況（Search Console、2026-11-24 時点の直近3か月）：クリック 339 回、表示 1.23 万回、CTR 2.8%、平均掲載順位 7.5 位。

ページごと：

| ページ | クリック | 表示 | CTR | 順位 |
|--------|---------:|-----:|----:|-----:|
| トップ | 124 | 3,694 | 3.36% | 8.4 |
| 港別（一覧） | 58 | 2,896 | 2.0% | 8.2 |
| マリックスライン | 53 | 3,281 | 1.62% | 6.0 |
| マルエーフェリー | 33 | 1,555 | 2.12% | 8.8 |

会社名のクエリ（抜粋）：

| クエリ | クリック | 表示 | CTR | 順位 |
|--------|---------:|-----:|----:|-----:|
| マリックスライン 運行 状況 | 9 | 1,362 | 0.66% | 5.1 |
| マリックスライン 運行状況 | 0 | 393 | 0% | 5.2 |
| マリックスライン 運行 状況 今日 | 13 | 383 | 3.39% | 4.3 |
| マリックスライン 運行 状況 リアルタイム | 11 | 163 | 6.75% | 3.3 |
| マリックスライン 運行 状況 明日 | 2 | 14 | 14.29% | 3.6 |
| マルエーフェリー 運行状況 | 7 | 288 | 2.43% | 6.9 |
| マルエー フェリー 運行 状況 今日 | 3 | 211 | 1.42% | 7.6 |
| マルエー フェリー 運行 状況 明日 | 5 | 37 | 13.51% | 4.4 |

ここから分かること：

- **マリックスラインのページは順位は良いのに、ほとんどクリックされていない**。会社名だけのクエリは公式サイトが選ばれている。一方で「今日」「リアルタイム」「明日」が付くと CTR は 3〜14% に上がる。つまり「公式より早く・まとめて分かる」と伝われば選ばれる
- **9割以上のクエリが「運行」**。サイトは「運航」だけなので、検索結果で検索語が太字にならない
- **船の名前・会社の別名で探す人がいる**（フェリー波之上・フェリーあけぼの・クイーンコーラル・Aライン・大島運輸 など、合わせて約 400 回の表示）。会社ページにその名前が無いので、ほとんど 8〜10 位以下になっている

## Clarifications

### Session 2026-11-24

- Q: 18-port-seo-pages で「運行」は画面に出さないと決めた。今回はどうするか → A: **説明文（description）にだけ**「運航（運行）状況」の形で1回添える。title・h1・本文は正しい「運航」のまま。隠しテキスト・meta keywords は引き続き使わない（18 の決定のうち、description についてだけ変える）

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 会社名で検索して、公式より早く分かるページだと気づく（Priority: P1）

「マリックスライン 運行 状況」と検索した人が、検索結果で公式サイトのすぐ下にこのサイトを見つける。タイトルと説明文から「今日・明日の欠航・遅延がリアルタイムで、まとめて分かる」ページだと分かり、クリックする。

**Why this priority**: マリックスラインのページは表示回数がサイトでいちばん多く（3,281 回）、順位も良い。CTR が上がれば、そのままクリックが増える。

**Independent Test**: 2つの会社ページの title と description を見て、会社名・「運航状況」・「今日・明日」・「リアルタイム」・「欠航・遅延」が入っていて、説明文に「運航（運行）」があることを確かめる。

**Acceptance Scenarios**:

1. **Given** マリックスラインの会社ページ, **When** title を見る, **Then** 先頭に会社名と「運航状況」があり、「リアルタイム」と「今日・明日」が入っている
2. **Given** マリックスラインの会社ページ, **When** description を見る, **Then** 「運航（運行）状況」の表記が1回だけあり、欠航・遅延が毎時更新で分かること、今日から4日分をまとめて見られることが書いてある
3. **Given** マルエーフェリーの会社ページ, **When** title と description を見る, **Then** マリックスラインと同じ形になっている（会社名だけが違う）
4. **Given** どのページ, **When** title・h1・本文を見る, **Then** 「運行」という字はどこにもない

---

### User Story 2 - 船の名前・会社の別名で検索して、その会社のページにたどり着く（Priority: P2）

「フェリー波之上 運航状況」や「Aライン 運行状況」で検索した人が、その船・会社の運航状況が載っているページを見つける。

**Why this priority**: 表示回数は約 400 回と小さめだが、今は受け皿が無いので伸びしろが大きい。

**Independent Test**: 会社ページを開き、その会社の船の名前と別名が description と本文に出ていることを確かめる。

**Acceptance Scenarios**:

1. **Given** マルエーフェリーの会社ページ, **When** 本文を見る, **Then** 運航している船の名前（フェリー波之上・フェリーあけぼの）と別名（Aライン・大島運輸）が見える文として出ている
2. **Given** マリックスラインの会社ページ, **When** 本文を見る, **Then** 運航している船の名前（クイーンコーラルクロス・クイーンコーラルプラス）が見える文として出ている
3. **Given** 会社ページ, **When** description を見る, **Then** その会社の船の名前が入っている
4. **Given** 会社ページ, **When** 船の名前・別名を見る, **Then** その会社と関係のない船・会社の名前は無い

### Edge Cases

- 会社の船が入れ替わったり（新造船・引退）、名前の無い会社が増えたりしたとき：船の名前・別名が無い会社は、その文を出さない。間違った船の名前を出すよりは何も出さない
- 説明文が長すぎるとき：検索結果で切れても大事な部分が残るように、会社名・「運航（運行）状況」・今日・明日・リアルタイムを先頭のほうに置き、船の名前は後ろに置く
- このサイトが扱っていない会社の船（例：フェリーあまみ、フェリーきかい）：載せない。扱っていない船の運航状況があるように見せない

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 会社ページの title は「<会社名> 運航状況」で始め、「リアルタイム」と「今日・明日」を入れる。「運行」は入れない
- **FR-002**: 会社ページの description には、会社名・「運航（運行）状況」（1回だけ）・今日・明日の欠航・遅延・毎時更新・今日から4日分をまとめて見られること、を入れる
- **FR-003**: トップ・港別（一覧）・港ごとのページの description にも「運航（運行）状況」を1回添える。title は変えない
- **FR-004**: 「運行」の字は description（と、同じ値を使う og:description）にだけ出す。title・h1・本文には出さない。隠しテキスト・meta keywords は使わない
- **FR-005**: 会社ページの本文に、その会社が運航している船の名前と、その会社の別名（旧社名・ブランド名）を、見える文として出す
- **FR-006**: 会社ページの description に、その会社の船の名前を入れる（別名は本文だけでもよい）
- **FR-007**: 船の名前・別名が無い会社では、その文を出さない（空の文や「船：」だけの表示を出さない）
- **FR-008**: 船の名前・別名は、このサイトが運航状況を載せている会社のものだけにする
- **FR-009**: 変えた後も、canonical・OG・sitemap・URL は今のまま（会社ページの URL は変えない）

### Key Entities

- **会社の別名・船の名前**: 会社ごとに、検索で使われる別の呼び方（旧社名・ブランド名）と、運航している船の名前。今の対象はマルエーフェリー（船：フェリー波之上・フェリーあけぼの、別名：Aライン・大島運輸）とマリックスライン（船：クイーンコーラルクロス・クイーンコーラルプラス）

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 公開前に、2つの会社ページの title・description・本文が FR-001〜FR-008 を満たしていることを確かめられる（「運行」が description 以外に無いことを含む）
- **SC-002**: 公開後 4 週間で、マリックスラインの会社ページの CTR が 1.62% から 3% 以上になる（掲載順位が今と同じくらい＝±1 位のとき）
- **SC-003**: 公開後 4 週間で、マルエーフェリーの会社ページの CTR が 2.12% から 3% 以上になる
- **SC-004**: 公開後 4 週間で、船の名前・会社の別名を含むクエリのクリックが、今の3か月分（3 回）より増える
- **SC-005**: サイト全体の平均掲載順位が今（7.5 位）より悪くならない

## Assumptions

- Google は「運行」と「運航」をほぼ同じ意味として扱っている。順位への効き目は小さく、狙いは検索結果での太字と「探していたページだ」と見えることによる CTR
- 公式サイトの順位は抜けない前提。会社名のクエリでは、2位以下で選ばれることを目指す
- 船の名前・別名は頻繁には変わらないので、会社ごとに決めておいてよい（変わったら直す）
- マルエーフェリーの別名「Aライン」はブランド名、「大島運輸」は旧社名。「エーライン」「a ライン」などの表記ゆれは、本文に「Aライン（エーライン）」のように書けば拾える
- 効果の確認（SC-002〜SC-005）は公開後 4 週間の Search Console の数字で行う

## Out of Scope

- 港ページへの内部リンクを島の名前で張ること（「徳之島」で検索されたときに港ページが出るようにする）→ 別の機能にする
- 船ごとのページを作ること
- このサイトが扱っていない会社（奄美海運など）の運航状況を載せること
- 構造化データ（JSON-LD）、会社ページの URL を slug にすること
