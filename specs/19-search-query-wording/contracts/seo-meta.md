# SEO Meta: 会社ページのタイトル・説明文・船の名前の1行

ここに書いていないことは [18-port-seo-pages の seo-meta.md](../../18-port-seo-pages/contracts/seo-meta.md) のまま。
og:title・og:description はタイトル・説明文と同じ（base.html.twig のまま）。

## 「運行」の出し方（FR-004）

- 出してよいのは `<meta name="description">` と `<meta property="og:description">` だけ。形は「運航（運行）状況」で、1 ページに 1 回
- title・og:title・h1・本文・meta keywords・見えない文字には出さない

## タイトル

| ページ | 変更前 | 変更後 |
|---|---|---|
| 会社別（例: マリックスライン） | マリックスライン 運航状況（今日・明日）+ suffix | マリックスライン 運航状況 リアルタイム（今日・明日）+ suffix |
| トップ・港別・港・エラーページ | — | 変えない |

## 説明文

| ページ | 変更後（太字が変えたところ） |
|---|---|
| 会社別（船の名前あり） | `<会社名>`**の運航（運行）状況をリアルタイムで。今日・明日の欠航・遅延を毎時更新し、今日から4日分を航路ごとにまとめて確認できます。運航船：**`<船の名前を「・」でつなぐ>`**。** |
| 会社別（船の名前なし） | 上から「運航船：…。」を除いたもの |
| トップ | 鹿児島〜奄美大島・徳之島・沖永良部・与論・沖縄（奄美航路）のフェリー**運航（運行）状況**。マルエーフェリー・マリックスラインの今日・明日の欠航・遅延を毎時更新し、リアルタイムで確認できます。 |
| 港別（全港） | 鹿児島〜奄美・沖縄の各港を出るフェリーの出港時刻と**運航（運行）状況**。マルエーフェリー・マリックスラインの今日・明日から4日分の欠航・遅延を、港ごとに毎時更新でお知らせします。 |
| 港 | `<呼び名>`を出るフェリーの今日・明日の**運航（運行）状況**と出港時刻。マルエーフェリー・マリックスラインの欠航・遅延を4日分、毎時更新でお知らせします。 |
| base の既定（エラーページなど） | 変えない（「運行」を入れない） |

例（マリックスライン）：

> マリックスラインの運航（運行）状況をリアルタイムで。今日・明日の欠航・遅延を毎時更新し、今日から4日分を航路ごとにまとめて確認できます。運航船：クイーンコーラルクロス・クイーンコーラルプラス。

## 会社ページの船の名前・別名の1行（FR-005〜FR-007）

h1 と「公式サイト ↗」の行（`.page-heading`）のすぐ下、最初の日付の見出しより上に置く。

```html
<p class="company-aliases small text-muted mb-4">運航船：フェリー波之上・フェリーあけぼの ／ 別名：Aライン（エーライン）</p>
```

| 船の名前 | 別名 | 出すもの |
|---|---|---|
| あり | あり | `運航船：<船>・<船> ／ 別名：<別名>・<別名>` |
| あり | なし | `運航船：<船>・<船>` |
| なし | あり | `別名：<別名>・<別名>` |
| なし | なし | `<p>` ごと出さない |

- `.page-heading` の下の余白（今の `mb-4`）は、1行を出すときは1行の側に持たせる（運航状況の位置がほとんど変わらないように）
- 375px 幅で折り返してよい。横スクロールを出さない
- 会社名・船の名前・別名は Twig の自動エスケープのまま出す
