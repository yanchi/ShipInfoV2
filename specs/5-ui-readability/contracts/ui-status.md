# UI Contract: ステータス表示

全ページで同じ記号・文言・見た目にする（FR-024・025）。`_status_badge.html.twig` がこの表のとおりに出す。

| 状態 | 記号 | 文言 | 見た目 | 異常の要約に入るか |
|---|---|---|---|---|
| 通常運航 | ✓ | 通常運航 | 緑の塗り | × |
| 運航予定 | ○ | 運航予定 | 白地に破線の枠 | × |
| 条件付・遅延 | ▲ | 条件付・遅延 | 黄の塗り・黒文字 | ○ |
| 欠航 | ✗ | 欠航 | 赤の塗り | ○ |
| 運休 | ■ | 運休 | 濃い灰の塗り | ○ |
| 便なし | — | 便なし | 塗りも枠も無し、灰色の文字 | × |
| 情報なし | ？ | 情報なし | 薄い灰の塗り | × |
| 不明 | ？ | 不明 | 薄い灰の塗り | × |

- 記号と文言だけで全種類を区別できること（SC-007）。「情報なし」と「不明」は記号が同じで文言で区別する
- 条件付・遅延は今の「●」から「▲」に変える（「○ 運航予定」と形が似ていて紛らわしいため）
- 運休は今の「-」から「■」に変える（「— 便なし」と紛らわしいため）

## 異常の行（FR-014）

`isAlert()` の行は次の3つを全部付ける。

- 行の左に太い線（条件付・遅延は黄、欠航は赤、運休は灰）
- 背景を薄い色にする
- ステータスを太字にする

## 出港済みの行（FR-008）

`isDeparted($now)` の行は、全体を薄くして（不透明度を下げる）「出港済み」の小さな文字を付ける。
