# Contract: 通知メール

## ヘッダー

| 項目 | 値 |
|---|---|
| From | `NOTIFY_FROM` |
| To | `NOTIFY_TO` をカンマで分け、前後の空白を除き、空のものを捨てたすべて（1 通の To に並べる） |
| Subject | `【ShipInfo V2】非通常運航ステータスを検出 (N件)` — N はまとめた後の (航路, 日付) の数 |
| 形式 | `text/plain; charset=utf-8`（HTML パートなし） |

V1 の件名 `【ShipInfo】…` と前方一致しないこと（`【ShipInfo V2】` で始まる）をテストで確かめる。

## 本文

テンプレート：`app/templates/email/irregular_statuses.txt.twig`

```
以下の運航情報で通常運航以外のステータスが検出されました。

{% for item in items %}
  会社名: {会社名}
  運航日: {Y-m-d}（{曜日}）
  方向　: {方向のラベル または 航路名}
  状況　: {状況}
{% if 備考 %}  備考　: {備考}
{% endif %}{% if ports %}  港　　:
{% for port in ports %}    - {港名}[ {H:i}発][ {船名}]：{状態のラベル}[（{備考}）]
{% endfor %}{% endif %}
{% endfor %}
```

### 状況の文言

| 航路×日付 | 港 | 状況 |
|---|---|---|
| 対象の状態 | あってもなくても | `OperationStatusEnum::label()`（欠航・条件付・遅延・運休・不明） |
| 通常運航 | 通常以外あり | `通常運航（途中の港に変更あり）` |
| 行なし・便なし | 通常以外あり | `情報なし（途中の港に変更あり）` |

### 並び

会社 ID → 運航日 → 航路 ID。港は出港予定時刻順（時刻なしは最後）。

## テストで押さえる例

| 入力 | 期待 |
|---|---|
| 航路×日付が欠航 1 件、港は無し | 件名 `(1件)`、本文に会社名・運航日・方向・`欠航`・備考 |
| 同じ航路・日付で航路×日付が欠航、港 2 つが欠航 | 1 件にまとまり、`港　　:` の下に 2 行 |
| 航路×日付は通常運航、途中の 1 港だけ欠航 | 1 件、状況 `通常運航（途中の港に変更あり）` |
| すべて通常運航・便なし・運航予定 | メールなし（結果 `none`） |
| 昨日の欠航・4 日先の欠航 | 載らない |
| 無効な会社・無効な航路の欠航 | 載らない |
| `unknown` | 載る（状況 `不明`） |
| `suspended`（ドック入り） | 載る（状況 `運休`） |
| `NOTIFY_TO=" a@example.com, ,b@example.com "` | To は `a@example.com`・`b@example.com` の 2 つ |
