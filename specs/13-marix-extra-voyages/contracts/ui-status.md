# UI Contract: トップの会社カードのバッジ（臨時便しか無い日）

[specs/12-marue-extra-voyages/contracts/ui-status.md](../../12-marue-extra-voyages/contracts/ui-status.md) の「出るところ」の、途中の港だけを出る日のバッジの決まりに1つ足す。ほかの表示（臨時便のバッジ・異常の要約・「◆ 臨時便 … 発」の1行・注意書き・凡例）は変えない。

## 航路単位が便なし（no_service）の日のバッジ

上から順に見て、最初に当てはまるものを出す。

| 今日その方向の便 | バッジ | 例 |
|---|---|---|
| 臨時便以外の行がある（始発港の行も含む。予備ルートの行など） | 今までどおり `midwayDisplay()`（臨時便の行を除いて決める。途中の港に行が無ければ「— 便なし」） | — |
| 途中の港を出る便が臨時便だけ | ◆ 臨時便（今のまま） | 9/27 上り（名瀬 05:50） |
| **臨時便以外の行が無く、始発港を出る臨時便がある** | **◆ 臨時便（追加）** | **8/27 下り（鹿児島 10:00）** |
| どれも無い | — 便なし（今のまま） | — |

臨時便以外の行が始発港にだけあるとき（状態の分からない定期便の予備ルートの行など）は、「◆ 臨時便」のバッジでその便を隠さない（PR #89 レビュー）。

- どの場合も、臨時便があれば下に「◆ 臨時便 〇〇 HH:MM発」の1行を出す（12 の FR-016。変えない）
- 会社を問わない（マルエーフェリーにも効く）

## 航路単位が便なしでない日

航路単位が通常運航なら、臨時便がある日は15-extra-voyage-badge で「▲ スケジュール変更」に変更（[contracts/ui-status.md](../../15-extra-voyage-badge/contracts/ui-status.md)）。それ以外は変えない。9/7 上りは「✗ 欠航」と注意書き、その下に「◆ 臨時便 那覇 07:00発」。9/6 下りは「▲ 条件付・遅延」、その下に「◆ 臨時便 鹿児島 09:00発」。
