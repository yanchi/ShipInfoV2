# UI Contract: 臨時便がある日の会社カード

[specs/12-marue-extra-voyages/contracts/ui-status.md](../../12-marue-extra-voyages/contracts/ui-status.md) の「出るところ」「トップの会社カード（FR-016）」と、[specs/13-marix-extra-voyages/contracts/ui-status.md](../../13-marix-extra-voyages/contracts/ui-status.md) を次のとおり変える。

**上書きする決まり**：「定期便の通常運航と臨時便が混ざっても『スケジュール変更』にしない」「航路のバッジ・注意書きは変えない」。

## 航路のバッジ

今日その方向に臨時便の行（状態が Extra）が1つ以上ある航路で、ふだんのバッジが次なら「▲ スケジュール変更」にする。臨時便が出港済みでも戻さない。

| ふだんのバッジ | 臨時便がある日 |
|---|---|
| ✓ 通常運航（航路単位、または途中の港の定期便） | **▲ スケジュール変更** |
| ○ 運航予定（途中の港の定期便） | **▲ スケジュール変更** |
| ✗ 欠航・■ 運休・▲ 条件付・遅延・？ 不明・？ 情報なし | 変えない |
| ◆ 臨時便（臨時便しか無い日。13） | 変えない |
| ▲ スケジュール変更（途中の港に欠航などが混ざる） | 変えない |

「▲ スケジュール変更」は今と同じ部品（`status-badge status-badge--delayed route-midway`、会社詳細ページへのリンク）。注意書きは出さない（今の「スケジュール変更」と同じ）。

## 臨時便の1行

```
鹿児島〜那覇（下り）                    ▲ スケジュール変更
◆ 臨時便 名瀬 03:50発・抜港あり
```

- 港・時刻・リンク・クラスは今のまま
- 今日を出る臨時便の運航のどれかで、その運航の最初と最後の港のあいだに寄らない港があれば、後ろに「・抜港あり」（data-model.md）
- 寄らない港が無ければ今のまま（「◆ 臨時便 名瀬 05:50発」）

## 例

| 日・方向 | 航路単位 | 臨時便 | 表示 |
|---|---|---|---|
| 10/27 マルエー下り | 通常運航（鹿児島 18:00 あけぼの） | 波之上 名瀬 03:50・本部 12:00（亀徳・和泊・与論なし） | ▲ スケジュール変更 / ◆ 臨時便 名瀬 03:50発・抜港あり |
| 9/7 マリックス上り | 欠航 | クロス 那覇 07:00・名瀬 21:20（本部〜亀徳は欠航） | ✗ 欠航＋注意書き / ◆ 臨時便 那覇 07:00発・抜港あり |
| 9/6 マリックス下り | 条件付・遅延 | クロス 鹿児島 09:00 | ▲ 条件付・遅延＋注意書き / ◆ 臨時便 鹿児島 09:00発 |
| 9/27 マリックス上り | 便なし | クロス 名瀬 05:50 だけ | ◆ 臨時便 / ◆ 臨時便 名瀬 05:50発 |

変えないもの：会社詳細・港別ページの便の行、異常の要約、凡例、注意書きの文言。
